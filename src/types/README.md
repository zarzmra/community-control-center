# Global TypeScript Type Definitions

This directory is for global, shared TypeScript types and interfaces that are used across multiple modules or components.

## Structure
- `index.ts`: Entry point for exposing types.
- `common.ts`: Common utility types (e.g. API responses, paginated results).
- `models.ts`: Future core data representations once schema entities are defined (e.g. Communities, Bots, Webhooks).
