# Shared Libraries and Utility Clients

This directory is reserved for system-wide configuration wrappers, client instantiations, and stateless utility functions.

## Future Integrations
- `db.ts`: Connection pool and configuration for **PostgreSQL** client.
- `redis.ts`: Client connection and configuration for **Redis** (caching and queues).
- `logger.ts`: Centralized application logger wrapper.
- `utils.ts`: Standard UI helper functions (like Tailwind merge, classnames, date formatters, etc.).
